# 실시간 통역 통화 (Korean Live Interpreter)

휴대폰으로 외국인과 통화할 때, **한국어 ↔ 영어**를 실시간으로 음성 통역해 주는 웹앱(PWA)입니다.
별도 설치 없이 휴대폰 브라우저에서 바로 실행됩니다.

## 동작 방식

실제 통화 오디오를 직접 가로채는 것은 iOS/안드로이드 정책상 일반 앱에서 불가능합니다.
그래서 이 앱은 시중의 통역 앱들과 동일하게 **스피커폰 방식**으로 동작합니다.

1. 통화를 **스피커폰**으로 켭니다.
2. 말하는 사람에 맞춰 버튼을 누릅니다.
   - 내가 한국어로 말할 때 → **🇰🇷 한국어 듣기** (영어로 번역·음성 출력)
   - 상대가 영어로 말할 때 → **🇺🇸 English 듣기** (한국어로 번역·음성 출력)
3. 인식된 말이 번역되어 화면에 표시되고, 번역 결과를 음성으로 읽어줍니다.

```
[상대방 영어 음성] → 마이크 → 음성인식(STT) → 번역 → 음성합성(TTS) → 한국어로 출력
[내 한국어 음성]   → 마이크 → 음성인식(STT) → 번역 → 음성합성(TTS) → 영어로 출력
```

## 사용 기술 (모두 무료, API 키 불필요)

| 기능 | 사용 기술 |
|---|---|
| 음성 인식 (STT) | 브라우저 내장 **Web Speech API** (`SpeechRecognition`) |
| 음성 합성 (TTS) | 브라우저 내장 **Web Speech API** (`SpeechSynthesis`) |
| 번역 | **MyMemory** 무료 공개 번역 API (키 불필요, 익명 일 5,000단어) |
| 앱 형태 | PWA (오프라인 UI 캐싱, 홈 화면 추가 가능) |

## 실행 방법

### 로컬에서 바로 실행
음성 인식/마이크는 `https` 또는 `localhost`에서만 동작합니다. 정적 서버를 띄우세요.

```bash
# Python
python3 -m http.server 8000
# 또는 Node
npx serve .
```

브라우저에서 `http://localhost:8000` 접속.

### 휴대폰에서 사용 (권장: GitHub Pages 무료 호스팅)
1. 이 저장소를 GitHub에 push 합니다.
2. 저장소 **Settings → Pages → Branch** 를 이 브랜치 / `main`, 폴더 `/ (root)` 로 설정.
3. 발급된 `https://<사용자>.github.io/<저장소>/` 주소를 휴대폰 브라우저로 엽니다.
4. **홈 화면에 추가**하면 앱처럼 사용할 수 있습니다.

> ⚠️ 음성 인식은 마이크 권한과 인터넷 연결이 필요합니다.

## 브라우저 호환성

| 브라우저 | 음성 인식 | 비고 |
|---|---|---|
| Chrome (안드로이드/PC) | ✅ | 가장 안정적 |
| Safari (iOS 14.5+) | ✅ | iOS는 한 발화 단위 인식 권장 |
| Firefox | ⚠️ | `SpeechRecognition` 미지원 환경 있음 |

## 한계 및 참고

- 시끄러운 환경에서는 인식 정확도가 떨어질 수 있습니다 → 스피커폰 볼륨/거리 조절.
- 무료 번역 API 특성상 일일 한도(약 5,000단어)가 있습니다. 한도 초과 시 안내가 표시됩니다.
- 더 높은 정확도가 필요하면 Google Cloud / Azure / OpenAI 등 유료 API로 교체할 수 있습니다
  (`js/app.js`의 `translate()` 함수만 수정).
