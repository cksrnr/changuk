# MOCK-UP UNIT 제작 리스트 — HTML 뷰어

기존에 엑셀(`97211110-...MOCKUP_TEST_R1.xls`)로 정리하던 **단위제품 제작 리스트**를,
설치 없이 브라우저에서 바로 보는 **HTML 인터페이스**로 변환한 것입니다.

## 보는 방법
`mockup/index.html` 파일을 **더블클릭**하면 브라우저에서 열립니다. (별도 서버·설치 불필요)

## 구성
- **전체 요약** : 제품 13종 / 총수량 17 EA / 총중량 1,754.4 kg (원본 SUM 시트 기준)
- **단위제품 상세** (13종) : 제품 정보 카드(현장명·SIZE·중량·수량·작성일 등) + 원자재 표
  (열별 정렬, 제품 내 검색, 부속·기타 자재 표 포함)
- **Shape Code** : 형상별 가공번호·절단길이·M.D·공차
- **도면** : MU-U-01 Production Elevation (원본 PDF에서 변환한 이미지)
- **전체 검색** : 상단 검색창에서 모든 제품의 자재를 한 번에 검색
- **인쇄 / PDF** : 우측 상단 버튼으로 인쇄·PDF 저장

## 데이터 출처 / 원칙
- 모든 값은 원본 엑셀에서 **자동 추출**한 것이며, 표시상 반올림 외에 **임의 수정·추론하지 않았습니다.**
- 데이터 파일: `data.js` (엑셀 추출 결과). 원본이 갱신되면 이 파일만 다시 생성하면 됩니다.

## 파일
```
mockup/
├── index.html   # 화면
├── style.css    # 스타일 (맑은 고딕 / 가는 회색선 / 제목14·본문11·표10)
├── app.js       # 렌더링·검색·정렬 로직
├── data.js      # 엑셀에서 추출한 데이터 (window.MOCKUP)
└── MU-U-01.png  # 도면 이미지
```
